# 📱 OLX iPhone Scanner & DeepSeek AI Appraiser

[![Версія Python](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/)
[![Тэрмінальны інтэрфейс](https://img.shields.io/badge/UI-Rich%20TUI-cyan.svg)](https://github.com/Textualize/rich)

[![Ліцэнзія](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Разумны тэрмінальны сканэр і экспертны ацэншчык аб'яў аб продажы iPhone на польскай пляцоўцы **OLX Польшча** (`olx.pl`) у рэальным часе на базе **DeepSeek AI**.

Пошук сапраўды выгадных прапаноў iPhone на OLX нярэдка патрабуе шмат часу: прадаўцы часта хаваюць інфармацыю пра рэальны стан акумулятара ўнутры доўгіх апісанняў (напрыклад, *"kondycja 84%"*, *"nowa bateria zamiennik"*), не пазначаюць наяўнасць блакіроўкі iCloud або запаўняюць катэгорыю аксэсуарамі (чахлы, пустыя скрынкі, ахоўнае шкло).

**OLX iPhone Scanner** цалкам аўтаматызуе гэты працэс: ён загружае свежыя аб'явы з эмуляцыяй браўзернага TLS-адбітка, адсявае смецце з дапамогай эўрыстык, а мадэль **DeepSeek AI** дакладна вызначае тэхнічныя характарыстыкі, захоўваючы ўсё ў лакальную базу SQLite і адлюстроўваючы вынікі на інтэрактыўнай панэлі ў тэрмінале.

## 🌟 Асноўныя Магчымасці

- **⚡ Абыход Cloudflare і аховы ад ботаў:** Выкарыстанне бібліятэкі `tls-client` з профілем Chrome 120, генерацыяй загалоўкаў і наладай шыфравання дазваляе працаваць з OLX без блакіровак IP і капчы.
- **🧠 Ацэнка DeepSeek AI:** Дакладнае выманне параметраў з неструктураваных польскамоўных тэкстаў:
  - Дакладная назва мадэлі і аб'ём памяці (ГБ)
  - Колер корпуса
  - Стан акумулятара ў працэнтах (`battery_health_pct`)
  - Візуальны і тэхнічны стан
  - Выяўленне дэфектаў і пашкоджанняў (разбітае шкло, праблемы з корпусам)
  - Спраўнасць Face ID і статус блакіроўкі iCloud
  - Сціслы вердыкт эксперта ў 1 сказ
- **🛡️ Эўрыстычны прэ-фільтр (Эканомія токенаў):** Адсякае чахлы, скрынкі, запчасткі, зарадныя прылады і іншыя маркі тэлефонаў (Samsung, Xiaomi, Pixel) рэгулярнымі выразамі **да** звароту да API.
- **🔄 Падтрымка проксі і рататараў:**
  - Прамое падключэнне (Direct TLS з вашага IP).
  - Аўтаматычнае выяўленне лакальнага рататара (па змаўчанні `http://127.0.0.1:8080`).
  - Асінхронная праверка і выбар найхутчэйшых HTTPS-тунэляў да OLX са спіса проксі.
- **📊 Інтэрактыўны тэрмінальны інтэрфейс (Rich Live TUI):**
  - Блокі ключавых паказчыкаў KPI (Усяго ў базе, Даследавана ШІ, Спраўныя, Пашкоджаныя, Прапушчаныя дублікаты).
  - Табліца з абнаўленнем у рэальным часе для нядаўна прааналізаваных iPhone.
  - Індыкатар прагрэсу і таймер да наступнага запуску ў рэжыме маніторынгу (`watch`).
  - Журнал падзей у рэальным часе.
- **⚡ Выяўленне дублікатаў і ранняе спыненне (Early Stopping):** Разлік кантрольных сум MD5 кожнай старонкі. Калі старонка цалкам складаецца з вядомых аб'яў, сканэр спыняе запыты да наступных старонак.
- **🌐 Шматмоўнасць:** Поўная лакалізацыя інтэрфейсу і сістэмных промптаў для 5 моў: беларуская (`be`), англійская (`en`), польская (`pl`), украінская (`uk`), нямецкая (`de`).
- **💾 Лакальная база даных SQLite з рэжымам WAL:** Надзейнае захаванне з падтрымкай паралельнага запісу праз Write-Ahead Logging у файл `olx_iphones.db`.

## 🏗️ Схема Працы

```text
  [ Паток аб'яў OLX.pl ]
               │
               ▼ (TLS-кліент - Адбітак Chrome 120 / Пул Проксі)
  [ Скрапер і HTML-парсар ]
               │
               ▼ (MD5 хэш старонкі / Зверка з базай даных)
  [ Праверка дублікатаў ] ────► (Ужо ёсць у базе? -> Прапусціць)
               │
               ▼
  [ Эўрыстычны фільтр ] ────► (Чахол / Скрынка / Іншая марка? -> Адхіліць)
               │
               ▼ (Шматпатокавая чарга ШІ)
  [ Аналізатар DeepSeek API ]
               │
               ├─► Аўта-выпраўленне JSON і валідацыя Pydantic
               ├─► Запіс у базу SQLite (`olx_iphones.db`)
               └─► Абнаўленне панэлі Rich TUI і файла лога
```

## 📦 Усталёўка

### 1. Сістэмныя патрабаванні
- Python версіі **3.10** або навейшай.
- API ключ DeepSeek (можна атрымаць на [platform.deepseek.com](https://platform.deepseek.com/)).

### 2. Кланаванне рэпазіторыя і віртуальнае асяроддзе

```bash
git clone https://github.com/k4rror/olx-iphone-scanner.git
cd olx-iphone-scanner

# Стварэнне і актывацыя віртуальнага асяроддзя
python -m venv .venv

# Linux / macOS:
source .venv/bin/activate

# Windows (PowerShell):
.venv\Scripts\Activate.ps1
```

### 3. Усталёўка пакета

```bash
pip install -e .
```

## 🚀 Хуткі Старт

### Майстар першага запуску

Запусціце праграму ў тэрмінале:
```bash
olx-scanner
```

Пры першым запуску аўтаматычна адкрыецца інтэрактыўны майстар наладкі:
1. Выбар мовы інтэрфейсу і промптаў (`be`, `en`, `pl`, `uk`, `de`).
2. Увод ключа DeepSeek API.
3. Выбар рэжыму падключэння (Direct TLS, лакальны рататар `127.0.0.1:8080` або файл са спісам проксі).
4. Наладка колькасці старонак і параметраў рэжыму маніторынгу.

Канфігурацыя будзе захаваная ў файле `scanner_config.json`. Вы можаце запусціць майстар паўторна ў любы час:
```bash
olx-scanner --setup
```

## ⚙️ Канфігурацыя

### Пераменныя асяроддзя (`.env`)
Ключ можна пазначыць у файле `.env` у корані праекта:
```env
DEEPSEEK_API_KEY=ваш_ключ_deepseek_api
```

### Файл канфігурацыі `scanner_config.json`
```json
{
  "language": "be",
  "api_key": "ваш_ключ_deepseek_api",
  "model": "deepseek-v4-flash-vision-exp",
  "proxy_mode": "rotator",
  "custom_proxy": "http://127.0.0.1:8080",
  "proxy_file": null,
  "pages": 3,
  "threads": 8,
  "watch": false,
  "interval": 120
}
```

## 💻 Прыклады Выкарыстання

### Стандартнае сканаванне
Сканаванне першых 3 старонак і завяршэнне працы:
```bash
olx-scanner --pages 3
```

### Бесперапынны маніторынг (Watch Mode)
Сканаванне 5 старонак, ацэнка навінак і паўтор кожныя 60 секунд:
```bash
olx-scanner --pages 5 --watch --interval 60
```

### Змена мовы камандай
Запуск праграмы на беларускай або польскай мове:
```bash
olx-scanner --lang be
olx-scanner --lang pl
```

### Выкарыстанне Проксі
Запуск са статычным проксі або файлам са спісам:
```bash
# Адзіночны проксі:
olx-scanner --proxy http://user:pass@127.0.0.1:8080

# Спіс проксі (з аўтаматычнай праверкай перад сканаваннем):
olx-scanner --proxy-file proxies.txt --min-proxies 20
```

### Радковы рэжым (Inline Mode)
Адключэнне поўнаэкраннага TUI для асяроддзяў CI/CD:
```bash
olx-scanner --inline
```

## 📋 Параметры Каманднага Радка

| Параметр | Сцяг | Апісанне | Па змаўчанні |
| :--- | :--- | :--- | :--- |
| **Наладка** | `--setup`, `--reconfigure` | Запуск інтэрактыўнага майстра наладкі | `False` |
| **Мова** | `--lang` | Мова інтэрфейсу і ШІ (`be`, `en`, `pl`, `uk`, `de`) | `en` |
| **Ключ API** | `--api-key` | Перавызначэнне ключа DeepSeek API | З канфігу / `.env` |
| **Мадэль** | `--model` | Ідэнтыфікатар мадэлі DeepSeek | `deepseek-v4-flash-vision-exp` |
| **Старонкі** | `--pages` | Колькасць старонак OLX за адзін цыкл | `3` |
| **Патокі ШІ** | `--threads` | Колькасць паралельных патокаў аналізу ШІ | `8` |
| **Рэжым Watch** | `--watch` | Уключэнне рэжыму бесперапыннага маніторынгу | `False` |
| **Інтэрвал** | `--interval` | Паўза паміж цыкламі ў секундах (рэжым watch) | `120` |
| **Проксі** | `--proxy` | Статычны проксі (`http://host:port`) | `None` |
| **Файл Проксі** | `--proxy-file`, `-pf` | Шлях да спіса проксі (`.txt` або `.json`) | `None` |
| **Мін. Проксі** | `--min-proxies` | Мінімальная колькасць спраўных проксі ў пуле | `15` |
| **Воркеры** | `--proxy-workers` | Колькасць патокаў для праверкі проксі | `150` |
| **Inline вывад**| `--inline` | Стандартны вывад без ачысткі экрана тэрмінала | `False` |
| **Файл лога** | `--log-file` | Шлях да файла запісу падзей | `olx_scanner.log` |

## 🗄️ База Даных (`olx_iphones.db`)

- **`iphone_offers`**:
  - `olx_id`: Унікальны ідэнтыфікатар аб'явы OLX.
  - `title`, `price`, `location`, `posted_at`, `description`, `url`.
  - `ai_analyzed`: Стан аналізу (`0` = чакае, `1` = завершана).
  - `model_name`: Распазнаная мадэль (напрыклад, `iPhone 13 Pro`).
  - `storage_gb`: Аб'ём памяці ў ГБ (напрыклад, `128`).
  - `battery_health_pct`: Стан батарэі ў % (або `NULL`).
  - `condition_state`: Апісанне візуальнага і тэхнічнага стану.
  - `is_damaged`: Ці пашкоджаны тэлефон (1 / 0).
  - `damage_details`: Падрабязнасці выяўленых дэфектаў.
  - `face_id_working`: Спраўнасць Face ID (1 / 0 / NULL).
  - `icloud_clean`: Адсутнасць блакіроўкі iCloud (1 / 0 / NULL).
  - `ai_summary`: Сціслы вердыкт эксперта.
  - `ai_raw_json`: Поўны неапрацаваны JSON ад DeepSeek.
- **`scanned_pages`**: Гісторыя прасканаваных старонак з кантрольнымі сумамі MD5.
