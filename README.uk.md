# 📱 OLX iPhone Scanner & DeepSeek AI Appraiser

[![Версія Python](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/)
[![Термінальний інтерфейс](https://img.shields.io/badge/UI-Rich%20TUI-cyan.svg)](https://github.com/Textualize/rich)
[![ШІ Двигун](https://img.shields.io/badge/AI-DeepSeek-magenta.svg)](https://www.deepseek.com/)
[![Ліцензія](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Розумний термінальний сканер та експертний оцінювач оголошень про продаж iPhone на польському маркетплейсі **OLX Польща** (`olx.pl`) у реальному часі на базі **DeepSeek AI**.

Пошук вигідних пропозицій iPhone на OLX зазвичай забирає багато часу: продавці нерідко ховають реальний стан батареї всередині довгих описів (наприклад, *"kondycja 84%"*, *"nowa bateria zamiennik"*), не вказують блокування iCloud або ж засмічують категорію аксесуарами (чохли, порожні коробки, захисне скло).

**OLX iPhone Scanner** повністю автоматизує цей процес: збирає актуальні оголошення з емуляцією браузерного TLS-відбитка, відсіває непотріб за допомогою евристик, а нейромережа **DeepSeek** аналізує технічний стан пристроїв, зберігаючи структуровані дані в базу SQLite та виводячи їх на інтерактивну панель у терміналі.

---

## 🌟 Основні Можливості

- **⚡ Обхід Cloudflare та захисту від ботів:** Використання бібліотеки `tls-client` із відбитком Chrome 120, генерацією заголовків та налаштуванням шифрування дозволяє безпечно працювати з OLX без блокувань та капч.
- **🧠 Експертна оцінка DeepSeek AI:** Точне вилучення даних із неструктурованих польськомовних описів:
  - Точна назва моделі та обсяг накопичувача (ГБ)
  - Колір корпусу
  - Залишок ємності батареї у відсотках (`battery_health_pct`)
  - Візуальний та технічний стан
  - Виявлення дефектів (тріщини скла, пошкодження корпусу тощо)
  - Справність Face ID та стан блокування iCloud
  - Лаконічний вердикт оцінювача в 1 речення
- **🛡️ Евристичний пре-фільтр (Економія токенів):** Відсікає чохли, коробки, запчастини, зарядні пристрої та смартфони інших брендів (Samsung, Xiaomi, Pixel) регулярними виразами **до** надсилання запиту до ШІ.
- **🔄 Підтримка проксі та ротаторів:**
  - Пряме підключення (Direct TLS з вашої поточної IP-адреси).
  - Автоматичне виявлення локального ротатора (за замовчуванням `http://127.0.0.1:8080`).
  - Асинхронна перевірка та вибір найшвидших HTTPS-тунелів із користувацького списку проксі.
- **📊 Інтерактивний термінальний TUI (Rich Live):**
  - Блоки ключових показників KPI (Всього в базі, Оброблено ШІ, Справні, Пошкоджені, Пропущені дублікати).
  - Оновлювана наживо таблиця нещодавно проаналізованих iPhone.
  - Індикатори прогресу та таймер зворотного відліку в режимі моніторингу (`watch`).
  - Журнал системних подій у реальному часі.
- **⚡ Виявлення дублікатів та рання зупинка (Early Stopping):** Формування хешів MD5 для кожної сторінки. Якщо сторінка на 100% складається з раніше збережених оголошень, сканування наступних сторінок зупиняється.
- **🌐 Багатомовність:** Повна локалізація інтерфейсу та системних промптів для 5 мов: українська (`uk`), англійська (`en`), польська (`pl`), німецька (`de`), білоруська (`be`).
- **💾 Локальна база даних SQLite з режимом WAL:** Надійне збереження даних із підтримкою паралельного доступу за протоколом Write-Ahead Logging.

## 🏗️ Схема Роботи

```text
  [ Стрічка оголошень OLX.pl ]
                 │
                 ▼ (TLS-клієнт - Відбиток Chrome 120 / Пул Проксі)
  [ Отримання та парсинг HTML ]
                 │
                 ▼ (MD5 хеш сторінки / Звірка з базою даних)
  [ Фільтрація дублікатів ] ────► (Вже збережено? -> Пропустити)
                 │
                 ▼
  [ Евристичний фільтр ] ────► (Чохол / Коробка / Інший бренд? -> Відхилити)
                 │
                 ▼ (Багатопотокова черга ШІ)
  [ Аналізатор DeepSeek API ]
                 │
                 ├─► Авто-виправлення JSON та валідація Pydantic
                 ├─► Запис до бази SQLite (`olx_iphones.db`)
                 └─► Відображення на панелі Rich TUI та запис у лог
```

## 📦 Встановлення

### 1. Системні вимоги
- Python версії **3.10** або новішої.
- API ключ DeepSeek (можна отримати на [platform.deepseek.com](https://platform.deepseek.com/)).

### 2. Клонування та налаштування середовища

```bash
git clone https://github.com/k4rror/olx-iphone-scanner.git
cd olx-iphone-scanner

# Створення та активація віртуального середовища
python -m venv .venv

# Linux / macOS:
source .venv/bin/activate

# Windows (PowerShell):
.venv\Scripts\Activate.ps1
```

### 3. Встановлення пакета

```bash
pip install -e .
```

## 🚀 Швидкий Старт

### Майстер першого запуску

Запустіть сканер у терміналі:
```bash
olx-scanner
```

Під час першого старту автоматично відкриється майстер первинного налаштування:
1. Вибір мови інтерфейсу та промптів (`uk`, `pl`, `en`, `de`, `be`).
2. Введення API ключа DeepSeek.
3. Вибір мережевого режиму (Direct TLS, ротатор `127.0.0.1:8080` або файл зі списком проксі).
4. Налаштування кількості сторінок та фонового режиму моніторингу.

Параметри зберігаються у файлі `scanner_config.json`. Ви можете викликати майстер знову в будь-який момент:
```bash
olx-scanner --setup
```

## ⚙️ Конфігурація

### Змінні оточення (`.env`)
Ключ API можна задати у файлі `.env` у корені проєкту:
```env
DEEPSEEK_API_KEY=ваш_ключ_deepseek_api
```

### Файл конфігурації `scanner_config.json`
```json
{
  "language": "uk",
  "api_key": "ваш_ключ_deepseek_api",
  "model": "deepseek-v4-flash-vision-exp",
  "proxy_mode": "rotator",
  "custom_proxy": "http://127.0.0.1:8080",
  "proxy_file": null,
  "pages": 3,
  "threads": 8,
  "watch": false,
  "interval": 120
}
```

## 💻 Приклади Використання

### Стандартне сканування
Сканує перші 3 сторінки оголошень та завершує роботу:
```bash
olx-scanner --pages 3
```

### Безперервний моніторинг (Watch Mode)
Сканує 5 сторінок, аналізує новинки та повторює цикл кожні 60 секунд:
```bash
olx-scanner --pages 5 --watch --interval 60
```

### Швидка зміна мови
Запуск інтерфейсу українською або польською мовою:
```bash
olx-scanner --lang uk
olx-scanner --lang pl
```

### Використання Проксі
Вказівка статичного проксі або файлу зі списком:
```bash
# Окремий проксі:
olx-scanner --proxy http://user:pass@127.0.0.1:8080

# Список проксі (автоматичне тестування перед скануванням):
olx-scanner --proxy-file proxy.txt --min-proxies 20
```

### Порядковий режим (Inline Mode)
Вимкнення повноекранного термінального інтерфейсу для CI/CD:
```bash
olx-scanner --inline
```

## 📋 Параметри Командного Рядка

| Параметр | Прапорець | Опис | За замовчуванням |
| :--- | :--- | :--- | :--- |
| **Налаштування** | `--setup`, `--reconfigure` | Запустити інтерактивний майстер налаштування | `False` |
| **Мова** | `--lang` | Мова інтерфейсу та ШІ (`uk`, `pl`, `en`, `de`, `be`) | `en` |
| **Ключ API** | `--api-key` | Перевизначити ключ DeepSeek API | З конфігу / `.env` |
| **Модель** | `--model` | Ідентифікатор моделі DeepSeek | `deepseek-v4-flash-vision-exp` |
| **Сторінки** | `--pages` | Кількість сторінок OLX за цикл | `3` |
| **Потоки ШІ** | `--threads` | Кількість паралельних потоків аналізу ШІ | `8` |
| **Фоновий режим**| `--watch` | Увімкнути безперервний цикл моніторингу | `False` |
| **Інтервал** | `--interval` | Пауза між циклами у секундах (режим watch) | `120` |
| **Проксі** | `--proxy` | Статичний проксі (`http://host:port`) | `None` |
| **Файл Проксі** | `--proxy-file`, `-pf` | Шлях до списку проксі (`.txt` або `.json`) | `None` |
| **Мін. Проксі** | `--min-proxies` | Мінімальна кількість робочих проксі у пулі | `15` |

| **Inline режим** | `--inline` | Стандартний вивід без очищення екрана | `False` |
| **Файл логу** | `--log-file` | Шлях до файлу журналу | `olx_scanner.log` |

## 🗄️ База Даних (`olx_iphones.db`)

- **`iphone_offers`**:
  - `olx_id`: Унікальний ідентифікатор оголошення OLX.
  - `title`, `price`, `location`, `posted_at`, `description`, `url`.
  - `ai_analyzed`: Статус аналізу (`0` = очікує, `1` = завершено).
  - `model_name`: Розпізнана модель (наприклад, `iPhone 13 Pro`).
  - `storage_gb`: Обсяг пам'яті (наприклад, `128`).
  - `battery_health_pct`: Стан акумулятора у % (або `NULL`).
  - `condition_state`: Опис візуального та технічного стану.
  - `is_damaged`: Чи є телефон пошкодженим (1 / 0).
  - `damage_details`: Опис виявлених дефектів.
  - `face_id_working`: Робота Face ID (1 / 0 / NULL).
  - `icloud_clean`: Відсутність блокування iCloud (1 / 0 / NULL).
  - `ai_summary`: Стислий вердикт експерта.
  - `ai_raw_json`: Повний сирий JSON від DeepSeek.
- **`scanned_pages`**: Історія сканування сторінок із контрольними сумами MD5.
