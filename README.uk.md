Сканує оголошення про iPhone на OLX Польща (`olx.pl`) і зберігає структуровані оцінки в локальній базі даних SQLite. Сторінки пошуку завантажуються з відбитком TLS Chrome 120, аксесуари та оголошення не від Apple відсіюються евристиками на регулярних виразах, а решта пропозицій надсилається до DeepSeek для вилучення моделі, обсягу пам'яті, стану акумулятора, пошкоджень і статусу блокування.

Два інтерфейси працюють з однією базою даних: термінальний інтерфейс Rich (`olx-scanner`) і вебпанель FastAPI/Jinja2 (`olx-dashboard`).

## Швидкий старт

```bash
git clone https://github.com/k4rror/olx-iphone-scanner.git
cd olx-iphone-scanner
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\Activate.ps1
pip install -e .
olx-scanner
```

Перший запуск відкриває інтерактивний майстер (мова, ключ API DeepSeek, режим проксі, кількість сторінок) і записує `scanner_config.json`. Ключ API DeepSeek обов'язковий.

## Можливості

- **Відбиток TLS:** `tls-client` налаштований на профіль Chrome 120 з емульованими заголовками, тому запити виглядають як звичайний браузер без сервісу розв'язування CAPTCHA.
- **Пул проксі:** списки проксі асинхронно перевіряються проти OLX через HTTPS-тунелі та ранжуються перед початком сканування. Підтримуються статичний проксі, локальний ротатор і пряме з'єднання TLS.
- **Евристичний пре-фільтр:** правила regex відхиляють чохли, коробки, зарядні пристрої, запчастини та інші бренди (Samsung, Xiaomi, Pixel) до будь-якого запиту до DeepSeek, що зменшує витрати токенів.
- **Вилучення даних DeepSeek:** кожне оголошення розбирається на типізовані поля (модель, обсяг пам'яті в ГБ, колір, відсоток стану акумулятора, стан, деталі пошкоджень, Face ID, блокування iCloud) плюс вердикт в одному реченні. Некоректні відповіді JSON виправляються та валідуються через Pydantic.
- **Дедуплікація та рання зупинка:** відбитки сторінок обчислюються з хешу MD5 ідентифікаторів оголошень на цій сторінці. Якщо сторінка 1 не змінилася з попереднього циклу або пізніша сторінка не додає жодної нової пропозиції, сканування зупиняється достроково.
- **Термінальна панель:** подання Rich Live з лічильниками KPI, таблицею нещодавно проаналізованих пропозицій, прогресом і журналом подій, що прокручується. `--inline` вимикає альтернативний екранний буфер для CI або неінтерактивних оболонок.
- **Вебпанель:** сторінки FastAPI і Jinja2 для керування сканером, таблиці пропозицій (фільтри, сортування, обране, нотатки), аналітики та експорту CSV.
- **Сховище:** SQLite у режимі WAL з індексованими стовпцями, безпечне для паралельних записувачів.
- **Інтернаціоналізація:** рядки інтерфейсу та промпти ШІ англійською, польською, українською, німецькою та білоруською мовами.

## Встановлення

### Вимоги

- Python 3.10 або новіший.
- Ключ API DeepSeek з [platform.deepseek.com](https://platform.deepseek.com/).
- Мережевий доступ до `olx.pl`.

### Встановлення пакета

```bash
git clone https://github.com/k4rror/olx-iphone-scanner.git
cd olx-iphone-scanner
python -m venv .venv

# Linux / macOS:
source .venv/bin/activate
# Windows (PowerShell):
.venv\Scripts\Activate.ps1

pip install -e .
```

Базове встановлення включає залежності вебпанелі (`fastapi`, `uvicorn`, `jinja2`). Щоб також запускати набір тестів і лінтер:

```bash
pip install -e ".[dev]"
```

## Використання

### Термінальний сканер

```bash
# Майстер налаштування (перший запуск або після видалення scanner_config.json)
olx-scanner

# Повторний запуск майстра в будь-який момент
olx-scanner --setup

# Один цикл по 3 сторінках у вибраному регіоні, без запитань
olx-scanner --non-interactive --pages 3 --region mazowieckie

# Безперервний моніторинг: 5 сторінок, потім 60 секунд очікування й повтор
olx-scanner --pages 5 --watch --interval 60

# Примусова мова інтерфейсу та промптів ШІ
olx-scanner --lang pl

# Проксі: один адрес або перевірений список із файлу
olx-scanner --proxy http://user:pass@127.0.0.1:8080
olx-scanner --proxy-file proxies.txt --min-proxies 20

# Неінтерактивний вивід для CI або логування
olx-scanner --inline
```

Регіон також можна передати як `--wojewodztwo`. Приймаються слаги воєводств, як-от `mazowieckie`, `slaskie`, `malopolskie`; пропустіть його, щоб сканувати всю OLX Польща.

### Параметри CLI

| Прапорець | Опис | За замовчуванням |
| :--- | :--- | :--- |
| `--setup`, `--reconfigure` | Запустити інтерактивний майстер налаштування | `False` |
| `--non-interactive`, `-y` | Пропустити попередні запити та використати збережену конфігурацію | `False` |
| `--lang` | Мова інтерфейсу та промптів (`en`, `pl`, `uk`, `de`, `be`) | config, інакше `pl` |
| `--region`, `--wojewodztwo` | Слаг воєводства, напр. `mazowieckie` | усі регіони |
| `--api-key` | Перевизначити ключ API DeepSeek | config / `.env` |
| `--model` | Ідентифікатор моделі DeepSeek | `deepseek-v4-flash-vision-exp` |
| `--proxy` | Один статичний проксі (`http://host:port`) | `None` |
| `--proxy-file`, `-pf` | Файл зі списком проксі (`.txt` або `.json`) | `None` |
| `--min-proxies` | Мінімальна кількість робочих проксі у пулі | `15` |
| `--proxy-workers` | Потоки для перевірки проксі | `150` |
| `--pages` | Кількість сторінок пошуку за цикл | `3` |
| `--threads` | Паралельні потоки для аналізу ШІ | `8` |
| `--watch` | Повторювати сканування в циклі | `False` |
| `--interval` | Секунди між циклами в режимі watch | `120` |
| `--inline` | Прокручуваний вивід замість повноекранного TUI | `False` |
| `--log-file` | Шлях до журналу виконання | `olx_scanner.log` |

### Вебпанель

```bash
olx-dashboard
```

Це запускає панель на `http://127.0.0.1:8000` і відкриває її в браузері за замовчуванням. Точка входу приймає:

| Прапорець | Опис | За замовчуванням |
| :--- | :--- | :--- |
| `--host` | Адреса прив'язки | `127.0.0.1` |
| `--port` | Порт прослуховування | `8000` |
| `--db` | Шлях до файлу бази даних SQLite | `olx_iphones.db` |
| `--no-browser` | Не відкривати браузер під час запуску | `False` |

Сторінки: `/scanner` (запуск/зупинка сканування), `/offers` (фільтр, сортування, обране, нотатки, видалення, експорт CSV), `/analytics` (статистика цін за моделями та маржа відносно середньої ринкової).

Панель надає JSON API над тими самими даними. Основні маршрути:

| Метод | Маршрут | Призначення |
| :--- | :--- | :--- |
| `GET` | `/api/stats` | Показники бази даних і зведення аналітики |
| `GET` | `/api/offers` | Посторінковий список пропозицій із фільтрами |
| `GET` | `/api/offers/{olx_id}` | Деталі однієї пропозиції |
| `POST` | `/api/offers/{olx_id}/favorite` | Перемкнути позначку обраного |
| `PATCH` | `/api/offers/{olx_id}/notes` | Зберегти нотатки користувача |
| `DELETE` | `/api/offers/{olx_id}` | Видалити пропозицію |
| `GET` | `/api/export` | Експорт CSV поточного фільтра |
| `GET` | `/api/models/stats` | Статистика цін і акумуляторів для моделі |
| `GET` | `/api/scanner/status` | Поточний знімок стану сканера |
| `POST` | `/api/scanner/start` | Запустити цикл сканування |
| `POST` | `/api/scanner/stop` | Зупинити активне сканування |
| `GET` | `/api/scanner/probe` | Кількість оголошень і сторінок для регіону |

### Конфігурація

`.env` у корені проєкту:

```env
DEEPSEEK_API_KEY=your_deepseek_api_key_here
OLX_PROXY=
```

`scanner_config.json`, який записує майстер і можна редагувати вручну:

```json
{
  "language": "pl",
  "api_key": "your_deepseek_api_key_here",
  "model": "deepseek-v4-flash-vision-exp",
  "proxy_mode": "rotator",
  "custom_proxy": "http://127.0.0.1:8080",
  "proxy_file": null,
  "region": "mazowieckie",
  "pages": 3,
  "threads": 8,
  "watch": false,
  "interval": 120
}
```

Прапорці командного рядка мають пріоритет над файлом конфігурації, а він над `.env`.

## Схема бази даних

SQLite, режим WAL, створюється автоматично в `olx_iphones.db`.

`iphone_offers`:

| Стовпець | Примітки |
| :--- | :--- |
| `id` | Первинний ключ |
| `olx_id` | Унікальний ідентифікатор оголошення OLX, індексований |
| `url`, `title`, `price`, `currency`, `location`, `posted_at`, `description`, `scraped_at` | Сирі дані оголошення |
| `ai_analyzed` | `0` = в очікуванні, `1` = проаналізовано, індексовано |
| `model_name`, `storage_gb`, `color` | Нормалізовані дані про пристрій |
| `battery_health_pct` | Ціле число, `NULL`, якщо продавець його не вказав |
| `condition_state`, `is_damaged`, `damage_details` | Стан і дефекти, індексовано за `is_damaged` |
| `face_id_working`, `icloud_clean` | `1` / `0` / `NULL` |
| `ai_summary` | Вердикт в одному реченні |
| `ai_raw_json` | Сира відповідь DeepSeek |
| `is_favorite`, `user_notes` | Додано вебпанеллю |

`scanned_pages`: `page_number`, `scanned_at`, `offers_total`, `new_offers`, `fingerprint` (MD5), `duration_s`. Використовується для перевірки ранньої зупинки.

## Тестування

```bash
pip install -e ".[dev]"
ruff check .
pytest tests/unit -v
```

Модульні тести працюють на фікстурах і не потребують мережевого доступу чи ключа API. CI запускає `ruff check .` і `pytest tests/unit/ -v` на Python 3.10, 3.11 та 3.12.

## Обмеження

- Вебпанель виконує один цикл сканування. Безперервний режим watch вимкнено у вебінтерфейсі (`WATCH_MODE_ENABLED = False` у `src/olx_scanner/web/app.py`); натомість використовуйте прапорець CLI `--watch`.
- Стан зберігається в одному локальному файлі SQLite. Немає розгортання на сервері, автентифікації та підтримки кількох користувачів; панель за замовчуванням прив'язується до `127.0.0.1`.
- Скрапер залежить від структури HTML OLX і ламається, коли розмітка змінюється. Немає офлайн-режиму чи вбудованого набору даних.
- Для аналізу потрібен платний ключ API DeepSeek. Без нього оголошення все одно зберігаються, але залишаються неаналізованими.
- Цей проєкт не пов'язаний з OLX. Дотримуйтеся умов надання послуг OLX і місцевих норм під час збирання даних.
